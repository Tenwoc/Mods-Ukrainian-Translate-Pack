**ae2helpers** — це мод-доповнення якості життя для Applied Energistics 2, розроблений для того, щоб зробити устави автовироблення плавнішими та компактнішими.

# Функціонал

**1. Картка імпорту результатів вироблення**
Спеціалізоване покращення для **постачальника шаблонів**.

- **Що воно робить:** Дозволяє постачальнику шаблонів **вводити** складники у машину та **виводити** результати обробки назад через той самий бік.
- **Перевага:** Усуває потребу в окремих шинах імпорту та додаткових каналах для простих обробних машинах.
- Корисно / необхідно тільки для машин, які не виводять результат в інші машини, або просто не здатні самостійно виводити результат.

**2. Автоматичне заповнення рецепта**
Покращений робочий процес **термінала майстрування**.

- **Що він робить:** Коли ви замовляєте недоступні предмети для рецепта у терміналі, сітка переходить у стан «очікування» із примарними предметами.
- **Перевага:** В момент, коли процесор завершить завдання, предмети **автоматично перенесуться** на сітку. Більше ніяких очікувань та повторних нудних тицянь! _Все як і повинно бути._
