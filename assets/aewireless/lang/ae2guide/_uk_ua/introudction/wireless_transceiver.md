# Бездротовий сполучник

<BlockImage id="aewireless:wireless_transceiver" scale="5" />
<RecipeFor id="aewireless:wireless_transceiver" />

МЕ Бездротовий сполучник — це пристрій, здатний розширювати мережу МЕ бездротовим шляхом, навіть крізь виміри.

## Основне використання

### Головний вузол

Головний вузол має бути приєднаний до мережі МЕ; він слугує джерелом каналів. Він реєструє іменований канал та забезпечує роботу усіх підключених підпорядкованих вузлів. Один головний вузол може керувати кількома підпорядкованими.

### Підпорядкований вузол

Підпорядкований вузол розміщується там, де потрібні канали; він отримує їх від головного вузла. Один підпорядкований вузол не може підключатися до кількох головних.

## Огляд інтерфейсу

Натисніть ПКМ по сполучнику, щоб відкрити його інтерфейс:

- **Список каналів** (ліва панель): відображає назви всіх доступних каналів. Натисніть, щоб вибрати канал; для пошуку введіть текст у поле над списком.
- Кнопка **Додати**: відкриває діалогове вікно для створення нового каналу.
- Кнопка **Видалити**: видаляє вибраний канал (потребує підтвердження).
- Кнопка **Режим**: перемикає між режимами «Головний» і «Підпорядкований».
- Кнопка **Відключити**: від’єднує поточний канал.
- **Перемикач одиниць енергії** (значок на панелі інструментів): перемикає показ енергії в AE або FE.
- **Перемикач відображення зв’язків** (значок на панелі інструментів, доступний лише для головного вузла): відображає лінії зв’язку з усіма підключеними підпорядкованими каналами.

### Використання списку каналів

1. Введіть текст у поле пошуку, щоб відфільтрувати канали.
2. Натисніть на канал, щоб вибрати його.
3. Натисніть **Додати**, щоб створити новий канал, або **Видалити**, щоб видалити вибраний канал.

## Бездротовий з’єднувач

<RecipeFor id="aewireless:wireless_connect" />

Бездротовий з’єднувач — це предмет, що використовується разом зі сполучником. Його також можна розмістити в слоті аксесуарів Curios.

### Прив’язка до каналу

1. Розмістіть бездротовий сполучник і встановіть для нього режим **Головний**.
2. Створіть або виберіть канал у графічному інтерфейсі.
3. Тримаючи в руках бездротовий з’єднувач, присядьте та застосуйте його по «головному» сполучнику, щоб прив’язати з’єднувач до цього каналу.

### Підключення блоків МЕ (пряме бездротове підключення)

Після прив’язки до каналу застосуйте з’єднувач по будь-якому пристрою AE2 (МЕ контролеру, інтерфейсу, приводу тощо). Ця дія безпосередньо прив’яже блок до мережі, без необхідності розміщувати підпорядкований сполучник.

### Перемикання режимів

Застосуйте крадькома з’єднувач по повітрю, щоб перемикатися між режимом **підключення** та **видалення**.

- **Режим підключення**: дозволяє прив’язувати з’єднувач до сполучників або блоків AE.
- **Режим видалення**: дозволяє видалити бездротове з’єднання клацанням ПКМ по вже підключеному блоку.

## Механіка енергоспоживання

Якщо цю функцію ввімкнено в конфігурації (`isEnergy`), енергоспоживання розраховується кожен такт:

| Режим | Формула | Типове значення (batteryMultiplier=1.0) |
| --- | --- | --- |
| Головний | Фіксоване значення `baseEnergy` | 100 AE/t |
| Підпорядкований (у тому ж вимірі) | Відстань до головного × `batteryMultiplier` | Залежить від відстані |
| Підпорядкований (між вимірами) | Відстань від початку координат (0,0) × `batteryMultiplier` | Залежить від розташування |

Для з’єднань між різними вимірами відстань розраховується на основі віддаленості підпорядкованого блоку від початку координат (0,0) у площині XZ; що далі розміщено підпорядкований блок, то більшою буде відстань.

## Конфігурація

| Параметр | Типове значення | Опис |
| --- | --- | --- |
| isEnergy | true | Умикає/вимикає споживання енергії |
| baseEnergy | 100.0 | Енергоспоживання головного вузла (AE/т) |
| batteryMultiplier | 1.0 | Енергоспоживання підпорядкованого вузла = відстань × множник |
| maxDistance | 0 | Максимальна дальність (0 = необмежена) |
| crossDimensional | true | Дозволяє з’єднання між вимірами |
| shiftAutoConnect | true | Автоматичне підключення під час присідання |

## Сумісність

- **FTB Teams**: Канали ізолюються для кожної команди, і лише учасники команди можуть взаємодіяти зі сполучниками своєї команди.
- **Curios**: Бездротовий з'єднувач можна оснастити у слот аксесуарів для автопідключення розміщуваних сполучників.
- **Jade/WTHIT**: У підказці блока показуватимуться подробиці про стан, власника та канал.
